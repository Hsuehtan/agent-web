# Hermess OEM Product Prototype

This directory contains a static, browser-viewable product prototype for the current Hermes Web UI / OEM project.

Open `index.html` directly in a browser. No dev server is required.

Prototype coverage:

- Login and first-run access
- Chat workspace, session list, model/profile switching, tool approvals
- History and global session search
- Group chat room with agent routing
- Jobs, kanban, platform channels, skills, plugins, memory, models
- Usage, performance, skill usage, logs
- Profiles, files, terminal, settings
- Mobile chat shell
- Product map and key user flows

The prototype is intentionally standalone and does not modify the existing app runtime.
